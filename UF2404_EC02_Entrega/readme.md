
# UF2404 — Principios de la Programación Orientada a Objetos

## Descripción

Colección de ejercicios prácticos desarrollados en Python para trabajar los principales conceptos de la **Programación Orientada a Objetos (POO)**.

El proyecto contiene 10 ejercicios independientes, cada uno implementado en un archivo Python separado.

## Técnicas y conceptos utilizados

A lo largo de los ejercicios se trabajan diferentes técnicas de programación orientada a objetos:

* **Clases y objetos**
* **Atributos de instancia y atributos de clase**
* **Métodos de instancia**
* **Encapsulación**
* **Composición entre objetos**
* **Herencia**
* **Herencia múltiple**
* **Polimorfismo**
* **Sobrescritura de métodos**
* **`super()` y MRO (Method Resolution Order)**
* **Métodos especiales como `__len__()` y `__str__()`**
* **Validación de datos**
* **Gestión de errores mediante excepciones**
* **Separación de responsabilidades entre clases**
* **Diseño extensible mediante polimorfismo**

## Ejecución

Cada ejercicio puede ejecutarse de forma independiente:

```bash
python ejercicio1.py
```

Por ejemplo:

```bash
python ejercicio8.py
```

No existe una dependencia entre los ejercicios; cada archivo contiene su propia implementación y demostración.

## Objetivo

El objetivo de la práctica es aplicar los principios fundamentales de la programación orientada a objetos mediante diferentes situaciones prácticas, prestando especial atención a la organización de responsabilidades, la reutilización de código y la extensibilidad de las soluciones.
